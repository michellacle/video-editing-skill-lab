# video-editing-skill-lab

Prototype lab for building practical video-editing skills and workflows.

## Goals
- Build reusable skills for editing short/long videos.
- Prototype end-to-end editing workflows (ingest → cut → caption → export).
- Keep a local ticket workflow for iterative development.

## Repo Ticketing
This repo has its own file-based ticket system:
- `tickets/backlog/`
- `tickets/do/`
- `tickets/doing/`
- `tickets/done/`

Rules are in `tickets/AGENTS.md`.

## Initial focus
- Define baseline video editing stack and tools.
- Build first skill for repeatable editing pipeline.
